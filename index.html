MLSec: Machine Learning Security

Student research projects from COMS 4995: Machine Learning Security at Columbia University, Spring 2026, Columbia's first course dedicated to the security of ML and AI systems.

Taught by Prof. Suman Jana. Projects advised by Daniel David, Teaching Assistant.

Projects  /  GitHub

About the Course

The course covered why ML systems break the assumptions of classical software security: adversarial examples, data poisoning and backdoors, model extraction and privacy leakage, and the new attack surface of LLM agents, including prompt injection and tool misuse. Students formed teams, proposed an original research project, presented the background literature, and submitted their papers through a conference-style review process on HotCRP.
