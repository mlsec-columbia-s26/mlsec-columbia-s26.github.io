# Machine Learning Security: Student Projects

**COMS 4995, Columbia University, Spring 2026**
Instructor: Prof. Suman Jana · Teaching Assistant: Daniel David

Columbia's first course dedicated to ML and AI security. 18 students worked in teams on 8 research projects, submitted through the course's HotCRP site (MLSecS26).

## Projects

1. **Early Commitment in LLMs and Its Amplification in Agentic Systems**
2. **Indirect Prompt Injection in Agent Workflows**
3. **Obfuscated Protocol for Federated Learning Defending Against Network Traffic Fingerprinting**
4. **Teacher-Student Architecture for Modeled Conversion Labels**
5. **TEN-Group: Trust-Independent Consensus for Byzantine-Robust Multi-LLM Systems**
6. **The Adversaries**
7. **Weak Poisoning in Multi-Agent Agentic RAG**
8. **When LLMs Know Too Much: Mitigating Unauthorized Access in Multi-User Retrieval-Augmented LLM Systems**
