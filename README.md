# Machine Learning Security: Student Projects

**COMS 4995, Columbia University, Spring 2026**
Instructor: Prof. Suman Jana · Teaching Assistant: Daniel David

Columbia's first course dedicated to ML and AI security. Students worked in teams on 8 research projects, submitted through the course's HotCRP site (MLSecS26).
